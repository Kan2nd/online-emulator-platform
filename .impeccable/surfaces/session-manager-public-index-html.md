# Player and library (session-manager/public/index.html)

Mode: Operate. Audience: a lecturer and classmates trying the platform in a laptop browser over Tailscale; the owner administers uploads. Job: pick a game, play it in its own container, save and load progress; upload a ROM; admin approves, rejects, deletes. Constraints: user-pinned palette black and blue; one game per tab; ~90 ms relayed latency shown honestly; no box art exists.
